    Which project is the starting point?

    Studio and the Aseprite file you link have to agree on one project. The starting point overwrites the other: its tile size, frame count and art. After that they stay in sync, with Aseprite's painting flowing back into Studio live.

    Link Aseprite online

    1. Install once. Download the extension from the Aseprite menu and double-click it. Aseprite adds it.
    2. Get a code. In the Aseprite menu click Link online, then Copy.
    3. Open Aseprite. Make a new sprite the same size as your tileset, in RGB colour.
    4. Paste the code. In Aseprite go to File ▸ Scripts ▸ Tileset Studio Link (online), paste the code and press Link.

    Now Studio's normal map shows up in Aseprite as a locked layer. Draw inside a group called Albedo and your art goes back to Studio. The dot by the Aseprite menu turns green when it works.

    Is it private?

    • Only you can see it. Your code is random and made just for your browser. Nobody can see your pictures without it, and nobody can guess it.
    • Nothing is saved. Your pictures pass through and are never written to a disk, a database or a log.
    • If you join late: say you open Aseprite after Studio. The relay holds the newest picture for a short while so Aseprite can still get it. It forgets it once everyone has left and it goes quiet.
    • The catch. Your pictures travel through Cloudflare's servers, like any online service, and anyone you give the code to can see them.
    • Change it any time. Your code stays the same between visits so Aseprite remembers it. If you shared it, showed it on a stream or just want a clean start, press New code: the old one stops reaching you at once. Paste the new code into Aseprite to link again.
    • Aseprite's side is not locked. Studio talks to the relay over a secure connection, but Aseprite cannot, so its half travels as plain text. Someone on your own network (shared Wi-Fi, say) could in theory read the code and the pictures. Fine at home, not great on a public network. For art that must stay private, use the folder link in Chrome or Edge.

    Export 3D models

    Send models to Blender or other 3D tools, and bring a refined version back with File ▸ Import 3D.

    glTF is Y-up like Blender, and Studio's axes read the same as Blender's. Use the same pixels-per-unit when you import again. Each model follows one bone rigidly; a face is sent as triangles (a Studio-made model comes back with its quads). Textures and UVs are not transferred.

    Tileset Studio

    Flow: Open tileset (PNG) → lay models over the art → Process → check the output → Export. Axes: X across (east-west), Y depth (north-south on the ground, bigger = nearer you), Z height (up). The view is the tileset's own projection (File > Projection). Top-down: a point (X, Y, Z) shows at canvas (X, Y − Z), so going deeper moves a point down the screen and rising moves it up. Isometric: X runs down-right, Y down-left, height up; the axis key at the bottom right of the view shows the directions. Model what the art shows: fronts stand on the floor line, tops sit at their height. Holes (art no model covers) show in magenta.

    More tools (each panel explains itself; hover any control): Free Draw (P) creates a custom shape or cuts/carves a closed solid from the same outline; Corner Radius rounds only that outline. It also works in the held 3D camera. File ▸ Import 3D / stamp adds models from an OBJ or another project, or stamps them over your art. Export ▸ 3D models writes glTF (with bones and animation) or OBJ for Blender and other 3D tools. References (left panel) lay another tileset over yours as a ghost. README.md has the full manual.

    Pen / touch: the left palette has every tool; palette tools are "armed" (press where to start, drag, let go). The bar at the bottom gives X/Y/Z locks, an exact value, "fine", apply and cancel. Two fingers pan and pinch-zoom; the top-right panel pans, zooms, looks round and frames. « / » at the top of either panel folds it away.

    Scaling snaps sizes to whole steps; a part smaller than the step (a thin leg) scales in the largest power-of-two step that fits it.

    Output view: drag to move the light, Shift+wheel for its height; wheel (or − / +) zooms, middle/right/Space-drag pans, ⛶ fits. Hover reads the pixel; double-click selects its model; "next hole ›" visits uncovered spots; "⚠ Tile problems" lists cells the importer will misread (click it for the Pieces view). Floor shows the floor plan from above: dark stripes = open underneath (a top on legs), light stripes = a gap between stacked parts.

    Into Godot: set the Name at the top of the Export menu, then Export ▾ → Godot bundle: one name.export.json with the art, maps and collision. Copy it into the Godot project; the Studio Import plugin unpacks it and builds name_tileset.tres by itself (and again whenever you export over it).
