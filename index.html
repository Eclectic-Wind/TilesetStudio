    Which art do you keep?

    Both programs must work on the same picture, so one side replaces the other: art, tile size and frame count. After that, your painting in Aseprite flows into Studio by itself.

    Not sure? Link with a new, empty Aseprite file and start from this tileset.

    Connect Aseprite: the steps

    You need Aseprite 1.3 or newer. Studio's Aseprite menu shows how far you've got.

    1. Install the extension (once). Download it from the Aseprite menu and double-click the file.
    2. Press Link online in the Aseprite menu.
    3. Choose which art to keep: this tileset or the Aseprite file. The other one gets replaced. Studio only asks when a tileset is open.
    4. Paste the code into Aseprite. Press Copy in Studio, open your file in Aseprite, then go to File ▸ Scripts ▸ Tileset Studio Link (online)…, paste and press Link.
    5. Press Set up file in Aseprite's link window, then paint inside the group called Albedo. Keep that window open while you paint.

    Next time: repeat steps 2 to 4. Aseprite remembers the code, so you only press Link.

    Using Chrome or Edge? Link a shared folder keeps your art on this computer. Pick an empty folder in Studio. Then in Aseprite use File ▸ Scripts ▸ Tileset Studio Link… and pick any file in that folder.

    What the words mean

    • Reference: a picture of the models in their base colours (the colours an imported model came with, else the art on them). Studio makes it, and it appears in Aseprite as the locked layer Reference (Studio), a guide for your painting.
    • Albedo: the plain colours you paint, without lighting. Only what's in the Albedo group goes back to Studio.
    • Sending is by button online. To stay within the free relay's limits, pictures go out when you press Send now in Aseprite or Send reference now here. The folder link updates by itself.
    • Room code: how the two programs find each other online. Treat it like a password.
    • Relay: the small online service that passes pictures between the two programs.
    Is it private?
    • Only you can see it. Your code is random and made just for your browser. Nobody can see your pictures without it, and nobody can guess it.
    • Nothing is saved. Your pictures pass through and are never written to a disk, a database or a log.
    • If you join late: say you open Aseprite after Studio. The relay holds the newest picture for a short while so Aseprite can still get it. It forgets it once everyone has left.
    • The catch. Your pictures travel through Cloudflare's servers, like any online service, and anyone you give the code to can see them.
    • Change it any time. Your code stays the same between visits so Aseprite remembers it. If you shared it, showed it on a stream or just want a clean start, press Use a new room code: the old one stops reaching you at once. Paste the new code into Aseprite to link again.
    • Aseprite's side is not locked. Studio talks to the relay over a secure connection, but Aseprite cannot, so its half travels as plain text. Someone on your own network (shared Wi-Fi, say) could in theory read the code and the pictures. Fine at home, not great on a public network. For art that must stay private, use the folder link in Chrome or Edge.

    Export 3D models

    Send models to Blender or other 3D tools, and bring a refined version back with File ▸ Import 3D.

    glTF is Y-up like Blender, and Studio's axes read the same as Blender's. Use the same pixels-per-unit when you import again. Models keep their skin weights; a face is sent as triangles (a Studio-made model comes back with its quads). Textures and UVs are not transferred.

    Tileset Studio

    Esc closes

    Open tileset → model over the art → check the output (it updates as you work while "auto" is on) → Export. Axes: X across, Y depth (bigger = nearer you), Z height. Model what the art shows: fronts stand on the floor line, tops sit at their height; holes (art no model covers) show in magenta.

    Projection

    The view is the tileset's own projection (File ▾ Projection). Top-down: a point (X, Y, Z) shows at canvas (X, Y − Z), so going deeper moves a point down the screen and rising moves it up. Isometric: X runs down-right, Y down-left, height up; the axis key at the bottom right of the view shows the directions.

    Tools in the panels

    Free Draw (P) creates a custom shape or cuts/carves a closed solid from the same outline; Corner Radius rounds only that outline. Facing turn (Properties) turns a model's or face's shading to where the art meant it to face; the shape stays. File ▾ Import 3D / stamp adds models from an OBJ or another project, or stamps them over your art. Export ▾ 3D models writes glTF (with bones and animation) or OBJ for Blender and other 3D tools. References lay another tileset over yours as a ghost. README.md has the full manual.

    Scaling snaps sizes to whole steps; a part smaller than the step (a thin leg) scales in the largest power-of-two step that fits it.

    Output view

    Drag to move the light, Shift+wheel for its height; wheel (or − / +) zooms, middle/right/Space-drag pans. Hover reads the pixel; double-click selects its model; "next hole ›" visits uncovered spots; "⚠ Tile problems" lists cells the importer will misread (click it for the Pieces view). Floor shows the floor plan from above: dark stripes = open underneath (a top on legs), light stripes = a gap between stacked parts.

    Pen and touch

    The left palette has every tool; palette tools are "armed" (press where to start, drag, let go). The bar at the bottom gives X/Y/Z locks, an exact value, "fine", apply and cancel. Two fingers pan and pinch-zoom; the top-right panel pans, zooms, looks round and frames. « / » at the top of either panel folds it away.

    Animating

    Press Animate, click a later frame on the timeline, select a model and press G to move it. Studio works out the frames in between; Space plays. Bones are only needed for things that bend. Press L and pick the Animation tab for short lessons.

    Painting in Aseprite

    The Aseprite ▾ menu links the two programs, so what you paint there shows on your models straight away. It works with or without animation, and the menu shows each step. Press L and pick the Aseprite link tab for short lessons.

    Into Godot

    Set the Name at the top of the Export menu, then Export ▾ → Godot bundle: one name.export.json with the art, maps and collision. Copy it into the Godot project; the Studio Import plugin unpacks it and builds name_tileset.tres by itself (and again whenever you export over it).
